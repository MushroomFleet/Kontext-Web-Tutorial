# Kontext-Web-Tutorial

A web-based **FLUX Kontext prompt showcase and tutorial** for instruction-based AI image editing. This interactive site presents 44 curated prompts organized by difficulty level, demonstrating precision image editing techniques using FLUX Kontext.

## Features

- 44 carefully curated FLUX Kontext prompts with example outputs
- Three difficulty tiers: Basic, Intermediate, and Advanced
- Basic prompts covering object modification, color changes, and simple edits
- Intermediate prompts for character consistency, multi-step edits, and scene composition
- Advanced prompts for style transfer, complex transformations, and creative techniques
- Prompt ID reference system with cheat sheets for quick lookup
- Dark-themed responsive UI built with Tailwind CSS
- Master prompt template for crafting your own Kontext instructions

## Usage

Open `index.html` in any modern web browser to browse the prompt showcase. No build step or server required.

### Structure

- `basic/` - Beginner-level prompt examples (19 prompts)
- `intermediate/` - Mid-level prompt examples (12 prompts)
- `advanced/` - Expert-level prompt examples (13 prompts)
- `images/` - Example output images for each prompt
- `cheatsheet1.md` / `cheatsheet2.md` - Quick-reference prompt cheat sheets
- `master-prompt.txt` - Template for building custom Kontext prompts
- `promptID.md` - Full prompt ID reference index
